# Sistema de Gestión de Base de Datos para Biblioteca

Proyecto relacional diseñado para administrar de manera eficiente el inventario de libros, el registro de socios/usuarios y el control de préstamos y devoluciones de una biblioteca.

---

## Características Principales

* **Control de Inventario:** Gestión de libros, autores, editoriales y categorías.
* **Gestión de Usuarios:** Registro y control de socios activos de la biblioteca.
* **Módulo de Préstamos:** Seguimiento en tiempo real de libros prestados, fechas de entrega y devoluciones.
* **Consultas Optimizadas:** Estructurado para consultas rápidas de disponibilidad y multas o historiales.

---

## Cómo Utilizarlo

1. Clona el repositorio en tu máquina local.
2. Importa el esquema de la base de datos en tu gestor SQL de preferencia (como MySQL, PostgreSQL, etc.).
3. Ejecuta los scripts de inserción de datos iniciales (si aplica) para probar las consultas y reportes de inventario y préstamos.
